# 🏥 Hospital Management System

A simple **Hospital Management System** built using **HTML, CSS, JavaScript, Node.js (Express)** and **MySQL**.  
This project demonstrates basic **CRUD operations**, **appointment scheduling**, and **frontend–backend integration**.

---

## 🚀 Features

### 🔐 Authentication
- Single admin login (frontend-based)
- Login session using `localStorage`
- Logout functionality
- Protected pages (cannot access without login)

---

### 👤 Patient Management
- Add new patients
- View patient list
- Basic form validation (name, email, phone)

---

### 👨‍⚕️ Doctor Management
- Add doctor details (name, specialization, email, phone)
- View doctors list
- Update doctor information
- Delete doctor records
- Pagination support for doctor list
- Doctor information by id

---

### 📅 Appointment Management
- Book appointments
- Select patient and doctor
- Appointment date & time handling
- View appointment list
- Update appointment status (Scheduled / Completed / Cancelled)
- Status-based UI coloring

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5

### Backend
- Node.js
- Express.js
